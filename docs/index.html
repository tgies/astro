What you're seeing is a running copy of MS-DOS 6, built from source by GitHub Actions from the leaked Microsoft source code. The disk images are from the latest release.

There are three modes. Boot floppy boots a minimal 1.44MB DOS floppy with just IO.SYS, MSDOS.SYS, and COMMAND.COM from the build artifacts.

Full install boots a hard disk image with DOS 6 installed, including all the standard utilities.

Build environment boots a hard disk image that also contains the full source tree, so you can build MS-DOS 6 from source inside the MS-DOS 6 built from that source. Just type BUILDALL USA.
